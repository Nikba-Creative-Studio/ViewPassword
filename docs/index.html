🔒 Zero data collection

Your passwords never leave your browser

ViewPassword requests no network permissions. It reads a field's value only when you click copy or reveal, and uses it solely for the clipboard or on-screen toggle. It cannot access passwords stored inside your browser's encrypted password manager.
