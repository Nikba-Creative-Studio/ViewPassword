Frequently asked questions

Installation, permissions, and the details that help ViewPassword work correctly.

How do I install and activate ViewPassword in Safari on Mac?
  1. Install ViewPassword from the App Store and open the app once.
  2. Open Safari, then choose Safari → Settings → Extensions.
  3. Enable the checkbox next to ViewPassword.
  4. Open ViewPassword's website access settings and choose Always Allow on Every Website.
  5. Refresh any pages that were already open.

Installation alone does not automatically grant access to every website; Safari requires you to approve this permission.

How do I activate ViewPassword on iPhone or iPad?
  1. Install ViewPassword from the App Store and open the app once.
  2. On iOS/iPadOS 18 or later, open Settings → Apps → Safari → Extensions. On earlier versions, open Settings → Safari → Extensions.
  3. Select ViewPassword and turn it on.
  4. Under Permissions, allow access on All Websites.
  5. Return to Safari and refresh the page.
Why does Safari ask for access to all websites?

Password fields can appear on any website, so ViewPassword needs page access to place its copy and reveal controls beside those fields. The extension processes values locally, only when you use an action, and does not transmit browsing or password data.

I installed the Safari extension, but the buttons do not appear. What should I check?

Confirm that ViewPassword is enabled, website access is set to Allow or Always Allow on Every Website, and the page was refreshed after activation. For Private Browsing, Safari requires the separate Allow in Private Browsing option.

Does ViewPassword read my saved password manager?

No. ViewPassword cannot open Safari, Chrome, or Firefox's encrypted password manager. It only works with a value already present in a field on the current webpage.

Is any password or browsing data collected?

No. ViewPassword has no analytics, remote servers, or network access. Copy and reveal actions are handled locally on your device.

🔒 Zero data collection

Your passwords never leave your browser

ViewPassword requests no network permissions. It reads a field's value only when you click copy or reveal, and uses it solely for the clipboard or on-screen toggle. It cannot access passwords stored inside your browser's encrypted password manager.
