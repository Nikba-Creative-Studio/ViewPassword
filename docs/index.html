Install in under a minute

The easiest way is straight from the Chrome Web Store. Prefer to load it manually? Follow the steps below.

  1. Download or clone the GitHub repository.
  2. Open chrome://extensions (or edge://extensions).
  3. Enable Developer mode (top-right toggle).
  4. Click Load unpacked and select the project folder.
  5. Hover a password field — the copy & reveal icons appear beside it.
🔒 Zero data collection

Your passwords never leave your browser

ViewPassword requests no network permissions. It reads a field's value only when you click copy or reveal, and uses it solely for the clipboard or on-screen toggle. It cannot access passwords stored inside Chrome's encrypted password manager.
